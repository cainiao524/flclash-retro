# 弹壳 VPN 1.9.6 界面核查与 FlClash 适配

## 依据和边界

原始材料是用户提供的旧版安装包，不是网页原型或旧版 Flutter 重做页面。本轮使用 Android 构建工具读取二进制布局、资源表和动画 XML，并检查了项目中复用的原 PNG。

没有启动旧 APK，也没有访问其账号、线路、广告或支付服务。因此下面的“原版”描述指静态资源，不证明实际启动画面、页面跳转、动画触发时机和服务器行为。旧应用的其他业务页面还参考了用户提供的静态分析；不把未经运行验证的行为写成确定事实。

## 视觉和结构核查

| 元素 | 原包证据 | 本轮还原与适配 |
| --- | --- | --- |
| 大面积蓝底 | `main_bg_color` 为 `#3E5D9C` | 两套主页保持整屏蓝，不嵌入上游仪表盘卡片 |
| 橙色强调 | `orange` 为 `#FF7901` | 圆盘文字、线路操作、功能图标使用同一强调色 |
| 标题栏 | `banner_layout.xml`；高度 46dp、标题 20sp | 标题恢复 20；触控高度至少 48，随大字体增高，不复刻位图上的假通知红点 |
| 连接圆盘 | `activity_main.xml`；200×200dp，主文字 35sp、副文字 18sp | 保留比例；用几何绘制白圆和半透明外圈，避免位图放大和首次解码空白；平板 240、手机横屏 160 |
| 按下反馈 | `selector_new_startroot_bg.xml` 指向普通与按下图片 | 白色表面按下变浅灰；另有轻微缩放，减少动态效果时不缩放 |
| 扩散动画 | `animation_new_root_default.xml`；2000ms、延时 150ms、1→1.4 倍、透明度 1→0、无限重复 | 去除原重做版旋转橙弧，改为约两秒一轮的白色扩散环；未声称完全复刻原运行时的启动延时及触发条件 |
| 线路框 | `shap_rl_round_bg.xml`：白底、5dp 圆角、1dp 灰边；30dp 圆形线路图 | 两套主页共用白色线路框，恢复橙色标签与圆形图案；使用通用地球图标，不捏造线路国家 |
| 更换按钮 | `shap_commant_bt_normal.xml`：白底、橙色细边、5dp 圆角 | 保留外观，点击区域至少 48；窄屏和大字时换行，线路名称最多三行且可查看完整提示 |
| 底部波浪 | `activity_main.xml` 的自定义 `WaveView` 高 60dp | 竖屏保留 60；横屏压缩；宽屏铺满，波浪与底色交界一致。曲线为 Flutter 重绘，并非取到了旧自定义视图的全部算法 |
| 底部底色 | 布局写明 `#B1FFFFFF` | 按原值叠加在蓝色上，不使用先前近白色卡片底 |
| 底部文字 | `tab_text_color` 为 `#3C3C3C` | 恢复深灰色；保留足够触控区域 |
| 原底部入口 | 原 Google、视频、永久权益 PNG 和角标 | 不再作为额外主页入口；默认功能页用相同蓝橙构图提供代理、配置、工具 |
| 抽屉 | 旧版为品牌头部与列表 | 保留抽屉形态；内容对应真实 FlClash 功能，不复制旧账号营销体系 |

旧首页真正的识别点是色块比例、大圆主操作、圆形图案和波浪，而不是“随便换成蓝橙色”。原版底部是快捷动作，并非页面导航，所以现在的三个入口仍执行功能跳转，不额外引入第二套主页或底部导航状态。

## 线路弹窗

原 `dialog_line.xml` 使用固定高度，并在列表前安排商业专线推广；`item_line.xml` 包括圆形图像、名称、质量文字、单选框。这次保留浅色列表、圆形标志、选中标识和关闭入口，移除推广，改为随可用窗口约束的滚动列表。

- 使用真实 `currentGroupsStateProvider`、`selectedProxyNameProvider` 和延迟数据，不填造“高速”或延迟数字。
- 普通选择组通过官方 `ProxiesAction.changeProxy` 请求切换，成功后再调用官方配置动作保存选择。
- 自动测速、故障转移、负载均衡等组不伪装成普通单选组，留在完整代理界面管理。
- 完整代理设置与测速始终有入口；没有删除上游代理组、提供器或高级设置。
- 直连模式点击更换时先解释，并允许用户明确选择规则或全局模式；不偷偷改变模式。
- RPC 失败显示原始错误，允许返回列表重试；请求未完成时避免重复选线。页面关闭后不继续更新已销毁的界面。

## 连接状态与功能边界

复古圆盘请求官方 `SetupAction.setRunning`，没有创建第二个 Core 进程、VPN 服务或自有状态机。连续操作仍交给上游“最新意图优先”的流程；界面只用请求序号避免过时回调覆盖新提示。

重要限制：当前 FlClash 的 `isStartProvider` 来源于乐观更新的运行时间，Android 服务命令也会立即返回受理结果。它们都不能证明系统 VPN 授权已完成、TUN 已建立或互联网可达。因此本轮只显示“正在提交操作”“已请求开启”等诚实提示，不把圆环动画或 Future 完成写成“VPN 已连接”。用户可继续进入上游仪表盘和网络检测功能确认实际连通性。

本轮未新增原生服务阶段桥接，尚未把所有系统授权取消、原生服务失败、正在断开等状态独立呈现在复古圆盘上。共享动作内部已处理、未向调用者抛出的失败，仍使用原有上游反馈。不能宣称六态 VPN 反馈已经全部完成。

## 旧软件的其他页面如何处理

| 旧页面体系 | 适配决定 |
| --- | --- |
| 账号、短信、微信登录 | 不接回旧账号系统；FlClash 的配置和订阅导入仍为真实入口 |
| 时长、充值、购买、支付结果 | 不接入旧商业支付，不伪装成有效商品 |
| 抽奖、排行、游戏、广告 | 不复制与代理控制无关的商业流程；抽奖转盘 `disc_bg` 不误当连接按钮 |
| 帮助、错误提示 | 不照搬“缓存过多必须重启手机”等缺乏依据的归因；尽量保留实际错误和恢复入口 |
| 配置、规则、连接、日志、DNS、TUN 等上游功能 | 继续使用上游页面、动作和底层能力；本轮不是删除功能后另造一个简化 VPN 客户端 |

这是保留外观辨识度、适配现有功能的重做，不是宣称旧软件全部商业页面及后台已经恢复。

## 适配与验证

现在只保留默认复古功能主页；配置、工具、仪表盘之间切换后返回已有复古首页，不新叠一份主页，也不把上游仪表盘改成默认首页。

手机竖屏上下排列，手机横屏及平板宽屏左右排列。短屏采用内容自然增高和滚动，不再估算固定高度；双倍字号下线路框和按钮可换行。动画尊重减少动态效果、后台、路由可见性和页面暂停。

本轮测试包括既有主页导航和动画测试，以及连接请求并发、异常及销毁、线路切换失败后重试、自动组只读、直连提示、320/640/1280 宽度双倍字体检查。

验证结果：界面与主页回归套件 177 项通过；之后补充普通横屏完整快捷入口、直连模式底部代理入口两项测试，最终连接控件和主页针对性回归 30 项通过；静态分析无问题。五张预览均实际查看。以上不等同于真机 VPN 连通性测试。

`docs/ui/` 中图片由当前 Flutter 组件测试渲染，不是旧 APK 运行截图，也不是 Android 真机截图。线路弹窗使用明确标为示例的配置与节点，无实测延迟。截图采用本机中文字体，真机字体可能略有差异。
